성경을 읽고, 보고, 지도로 걷는 무료 통합 성경 앱 〈BIBLE INSIGHT〉

성경 통독이 어렵게 느껴지거나, 아이들과 함께 재미있게 성경 인물과 지리를 배우고 싶으신가요? 〈BIBLE INSIGHT〉는 66권 성경 본문부터 시각화 자료, 지리 지도, 캐릭터 애니메이션까지 하나로 묶어 누구나 무료로 사용할 수 있도록 만든 성경 학습 앱입니다.

✨ 주요 기능 한눈에 보기
• 구약(39권)·신약(27권) 본문 읽기 & 원어 대조: 원하는 책·장·절로 바로 이동하고, 히브리어·헬라어 원어 뜻까지 함께 살펴볼 수 있습니다.
• 디즈니풍 3D 인물 애니메이션 (31명): 아담과 하와, 노아, 아브라함, 이삭, 모세, 다윗, 에스더, 예수님, 바울 등 성경 핵심 인물 31명을 생생한 디즈니풍 캐릭터와 연령별(유년부~성인·장년) 해설·퀴즈로 만날 수 있습니다.
• 성경 지리 아틀라스: 고대 근동·가나안·지중해 통합 지도 위에서 시대별 왕국 영역, 고대 도로, 인물 여정 코스 지도를 성경 본문과 연동해 탐험할 수 있습니다.
• 매일 큐티(QT) & 시각화 인포그래픽: 매일 말씀카드 묵상과 성경 66권 연계성 지도로 말씀의 전체 흐름을 한눈에 정리할 수 있습니다.
